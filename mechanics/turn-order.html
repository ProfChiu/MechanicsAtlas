The rewards never changed. Only the rule about who picks first did, and it moved the scores more than any single choice.

What designers take from this

  1. Turn order is a resource. With fixed order, the first seat scored 15 and the last scored 3 from the same choices.
  2. Share it, steer it, or sell it. Rotate the first player, give it to last place, or let players bid for it.
  3. Every system has a side effect. Rotation is fair but predictable; catch-up order can reward hanging back; bidding adds a second economy.
You'll see this in: Puerto Rico, Power Grid, Agricola, Twilight Imperium.

What designers take from this

  1. Goals name shapes. Players read the board as a puzzle: which cells could still become a line, a block, a corner?
  2. Overlap is the skill. One tile that serves two goals scored 8 points; an average tile scored about 1.
  3. Conflicting goals create tension. When two patterns want different colours in the same cell, every placement is a choice about which goal to give up.
You'll see this in: Azul, Cascadia, Patchwork, Sagrada.
